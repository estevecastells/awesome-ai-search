# Awesome AI Search [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of tools, first-party documentation, research and datasets for measuring and improving how brands and publishers appear in AI-generated search and answer experiences.

AI search increasingly combines traditional retrieval with synthesized answers and citations. This list focuses on observable practices: crawl and index controls, prompt-based visibility measurement, citations, referral traffic and content quality. No tool or tactic guarantees inclusion; behavior varies by engine, model, location and time.

This is deliberately a curated list, not an exhaustive directory. Entries need a live canonical URL, direct relevance to AI search and public evidence for the capability described. Listings are not endorsements, and paid placements, affiliate links and reciprocal listings are not accepted.

## What Is AI Search, GEO and AEO?

- **AI Search**: answering a query with a response generated by a large language model, often with citations, instead of only a ranked list of links.
- **GEO (Generative Engine Optimization)**: improving content, entities and authority so generative engines can find, understand and cite them.
- **AEO (Answer Engine Optimization)**: closely related work focused on becoming a useful answer to specific questions.
- **AIO**: an ambiguous abbreviation that may mean Google AI Overviews or AI optimization, depending on context.

Common measurements include:

- **Visibility or Mention Rate**: how often a brand appears across a defined prompt set.
- **Share of Voice**: a brand's mentions relative to a defined competitor set.
- **Citations**: source URLs linked from generated answers.
- **Sentiment**: how a brand is described.
- **AI Traffic**: visits and conversions referred by AI assistants.

Generated answers are non-deterministic. Reproducible reporting should record the engine and model, locale, prompt set, run date, frequency and sample count. Treat visibility and share-of-voice scores as vendor-defined estimates, and validate them against first-party citation and referral data when available.

## First-Party Guidance and Measurement

## Technical GEO

Protocols and validators that help search and retrieval systems discover and interpret current site content. None guarantees inclusion in a generated answer.

- [IndexNow](https://www.indexnow.org/documentation) - Protocol for notifying participating search engines when URLs are added, updated or deleted.
- [llms.txt](https://llmstxt.org/) - Community proposal for publishing an LLM-oriented content index; adoption is experimental, and Google Search says it does not use the file.
- [Rich Results Test](https://search.google.com/test/rich-results) - Test which structured data Google can read on a page.
- [Schema Markup Validator](https://validator.schema.org/) - Validate Schema.org markup independently of a specific search feature.
- [Schema.org](https://schema.org/) - Vocabulary for structured data used by search features; no special schema is required for AI Overviews or AI Mode.
- [WordLift](https://wordlift.io/) - Knowledge-graph and structured-data tooling for entity-based search workflows.

## APIs and MCP Servers

Documented programmatic access to AI-search visibility data. Listed alphabetically.

- [Canonry API and MCP](https://github.com/Canonry/canonry) - Open-source, self-hosted AEO monitoring and execution with a public OpenAPI surface and progressive MCP catalog.
- [Keyword.com Developer Platform](https://keyword.com/docs/) - Two REST APIs and an OAuth MCP spanning traditional rank tracking and AI visibility.
- [LLM Pulse API](https://llmpulse.ai/api-docs) - A 94-operation REST API for visibility metrics, raw answers, citations, traffic, Search Console, reputation, studies, shopping, ads, projects and automation.
- [LLM Pulse MCP](https://llmpulse.ai/api-docs/integrations) - An 88-tool registered MCP surface with OAuth, read/write scopes and per-plan tool filtering.
- [Peec AI API and MCP](https://docs.peec.ai/) - Public references for reports, raw answers, citations, fan-out queries, shopping, agent traffic and configuration.
- [Profound API](https://docs.tryprofound.com/rest-api/introduction) - Programmatic access to answer-engine insights, raw prompt data and agent analytics.
